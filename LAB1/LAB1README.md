Pick a type of retail web application that you will create for this course. You can pick a category of your own or from one of the following (except for books):
Computers & IT Accessories
Electronics
Clothing
Shoes
Furniture
Toys
Sports & Outdoors
Movies
Music
Kitchen appliances
Games
Jewelry
Pick a name for your retail web application. The name of the store must include your first name. Example, Becca's Gems would be a name for a retail store for a student named Becca creating a jewelry retail web application.
Write a detailed summary description of your application. The summary should be at least two paragraphs with at least three sentences each. This is the information that will be on the main page of your application when we build the application in subsequent labs.
Include the type of app, name of app, and summary description in the Readme.md file of your week 1 folder.
